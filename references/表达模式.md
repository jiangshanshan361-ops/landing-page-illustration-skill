# 功能说明配图的表达模式

只读取、采用与当前需求相关的模式；以下是可选结构，不要求每张图包含全部元素。

## 同帧画质 / 调色对比

优先使用一张完整画面内的左右分割形式，避免两个相似小图让用户来回找差异。

- 两个版本共享图片尺寸与位置，通过左右遮罩拼接。分割线可在约 40%–60% 间调整，经过有细节或颜色变化的区域。
- 加 `#AFD34E` 竖向分界线，圆形双向箭头滑块作为 UI 示意；静态画板不宣称可拖动。
- 清晰度：同帧局部放大，左侧低细节/模糊，右侧清晰；建议标签 `LOW DETAIL` / `4K DETAIL · PREVIEW`。没有实际 4K 文件时保留 preview 语义。
- 调色：同一原帧，自然色与暖电影色拼接；只改颜色相关参数，保持人物、构图和光线方向。标签 `NATURAL` / `WARM CINEMA`。
- 画质、调色、运动各自独立标题与 icon；两种对比可上排并列，运动放下排宽幅。

## 原图驱动动作

左侧小型 `SOURCE IMAGE` 卡，右侧更大的连续结果：蒸汽上升→窗帘轻动→镜头缓慢推进。使用同一人物、物件和背景。

- 若是三个独立控制能力，用一条主干分三支；若是一个连续动作，则使用顺序连线和时间码。两者不要混用。
- 结果图必须足够大。允许一张大结果加两张辅助帧，但连接关系仍需一眼看懂。

## 故事 / 创意到成片

- 创意到成片：左侧一张简短 UI 创意卡；中间三镜头；右侧成片封面和播放符号。中间镜头不应成为无法识别的小缩略图。
- 连续故事：场景建立→人物动作→关键结果，例如雨夜街道→推门入咖啡馆→桌面信封。用 `01 / 02 / 03` 和简短动作词表达因果。
- 远景、中景、特写服务于同一故事，不混用 unrelated 人物或场景。成片封面可复用关键镜头。

## 时间延长 / 运动连续性

- 上方突出一张主画面；下方横排圆角连续帧，可放大当前帧，以绿色描边和竖直播放头突出连接点。
- 下方两色片段条分别标 `ORIGINAL` 和 `EXTENDED`；时间码与片段长度匹配。
- 接缝附近使用真正相邻的动作帧，呈现例如推门→跨过门槛→走向桌边。不要以倒放、重复播放或扩展边缘充当时间延长。
- 展示流畅度时，应取同一时间范围内可追踪的运动，点线附着在同一物体或人物部位。切换机位的故事镜头不能当作插帧证据。

## 移除物体 / 移除文字

- 两个独立组：A 移除指定物体，B 移除叠加字幕。每组将类型 icon、输入、处理箭头、输出放在同一底板内。
- 输入输出同帧、同裁切、同光线；只修指定区域。其他人物、背景和细节保持一致。
- 若字幕本来是独立 UI 层，只隐藏字幕层即可表达文字移除；物体修补必须保持局部纹理合理。

## 角色 / UGC / 情感互动

- 同一角色多场景：四宫格自然人像、咖啡店、工作室、时尚造型；五官与发型一致，至少两套服装。换装区域独立分层。
- 人物驱动口播：大幅人物画面结合波形、播放头和简短字幕，体现声音与口型配合；不要以产品静物代替 UGC。
- 双人互动：两张原创成年角色输入小卡汇入结果；拥抱、轻吻各有独立输出帧，不用同一结果代表两种动作。

## 产品 / 风格组

- 产品展示优先三张有明确差异的图：盖合棚拍、开盖纹理特写、环境或 CGI 展示。保持产品身份一致，景别、视角、盖子状态可变。
- 用户指定仅三张图时，不额外添加重复角度缩略图。标签为空白需求优先，不擅自加商标。
- 写实→动漫：同一人物、构图、背景和动作，以一张来源分支到风格结果。只改变视觉风格。

## 音乐 / 歌词 / 字幕

- 歌词示意以舞台或故事图为底，放两行原创短英文歌词，当前词绿色高亮。
- 旁边三段可拆分字幕片段与简化时间标尺；波形、音符、播放头辅助说明，不堆积装饰音符。
- 音乐演示可用一张环境主图和两张表演细节图，配一个简洁播放器，保持主体优先。

## 多比例 / 导出

- 同一母版封面放入真实比例的 16:9、9:16、1:1 中性画框，流程汇合到一张下载/文件说明卡。
- 完整保留人物/产品优先。母版不能安全裁为竖图时，用 contain/FIT 加中性留边，不横向拉伸，不换成另一张生成图。
- 旁边列三份缩略图、比例、简短文件名及状态，例如 `Export package`、`Ready to save`。只表示导出示意，不声称实际文件已经导出。
- 参考尺寸可用 1920×1080、1080×1920、1080×1080。卡片里不要额外增加网页 CTA。

## 社媒卡组

横向配图中组织多张竖版内容卡：产品、城市知识、原创角色故事等。Hook 与字幕区简洁明确，Faceless 内容不露真人脸。生日祝福可作为独立卡，不承诺内容必定爆款。
